# Munajaat Maqbool — مناجات مقبول

**The Accepted Whispers** — a free, ad-free, no-tracking trilingual (Arabic / Urdu / English) dua app, based on the classic collection *Munajaat-e-Maqbool* by Maulana Ashraf Ali Thanwi (rahimahullah). Published as **Sadqah Jaariyah**.

[![Live app](https://img.shields.io/badge/open%20app-munajaat--maqbool.netlify.app-1a5632)](https://munajaat-maqbool.netlify.app)

## Features

- 📿 Duas organised by day of the week, with Arabic text, Urdu and English translations, and references
- 🕌 Arabic set in the beautiful **Digital Khatt IndoPak** typeface (classic 13-line mushaf style)
- 🔍 Full-text search across all three languages
- 🔖 Bookmarks, adjustable font sizes and line spacing, light & dark themes
- 📴 Works fully offline once installed (PWA)
- 🚫 No ads, no accounts, no tracking, no cost — forever

## Install

- **Web / any device**: <https://munajaat-maqbool.netlify.app> — "Add to Home Screen"
- **Android**: available on Google Play (org.munajaat.maqbool)
- **Windows**: available on the Microsoft Store

## Tech

Plain HTML/CSS/JS progressive web app — no frameworks, no build step.
Deploy by serving this folder from any static host.
